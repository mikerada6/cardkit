## Per-resource patterns

The library has no HTTP resources; the recurring artifact kinds are:

| Artifact kind | Where it lands | Notes |
|---|---|---|
| Immutable value object | `record`/`enum` in its owning package (`core.card`, `games.poker`) | equal-by-value; no `.internal` |
| Mutable domain object | its owning package (`Deck` in `core.deck`, `GameSession` in `games.session`) | mutation confined to lifecycle methods |
| Evaluation algorithm | strategy/ranker in `games.poker`, impl under `games.poker.internal` | one `HandEvaluator` strategy per `PokerVariant` |
| Domain exception | `core.error` | small descriptive set, not generic `RuntimeException` |
| Class logger | field in the class it serves | SLF4J `LoggerFactory.getLogger(Xxx.class)`, one per class |
| Unit test | `src/test/java/...` mirroring the main package | naming `unitOfWork_condition_expectedResult`; fast/offline |
| Test vector fixture | `src/test/java/.../<domain>/vectors` or a fixtures class beside the test | first-class named fixtures per category/tie-break |
| Cross-module acceptance test | `games` module, `...games/acceptance/` | offline, `SeededRandomSource`; runs under `-P it` |
| ArchUnit rule | `core`/`games` test source | enforces `games → core` (never reverse) and `.internal` non-export |

## CI lanes

- **Fast (default, `./mvnw verify`)** — unit tests + ArchUnit. Fully offline, no Docker.
- **Integration (`./mvnw verify -P it`)** — cross-module acceptance tests. Still offline
  (no Testcontainers/infra — the library owns no I/O). Kept green-and-empty until 0009/0017 populate it.

## Not present (per ADR-0001)

No `docker-compose.yml`, no `src/main/resources` app config, no Flyway/`db/migration`,
no `openapi.yaml`, no Angular/frontend tree, no actuator/Micrometer/OTel wiring. A future
service wanting these is a separate consuming project.
